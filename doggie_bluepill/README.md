## STM32F103C8t6 (bluepill) Hardware Abstraction

This section provides the hardware abstraction layer for the STM32f103 (a.k. bluepill) microcontroller, enabling seamless integration with Doggie and evilDoggie for CAN Bus operations. It includes configurations both standard and offensive functionalities. For detailed documentation, refer to the project [documentation](https://infobyte.github.io/doggie/).
